# AA Digital World storefront

A responsive product catalog for AA Digital World. Each listing opens WhatsApp with a message about that product, using the business number `+234 802 581 6245`.

## GitHub Pages

The static website is in `public/`. The included GitHub Actions workflow deploys it when changes are pushed to `master`.

1. Push this project to a GitHub repository.
2. In the repository, open **Settings → Pages** and set the build source to **GitHub Actions**.
3. Push to `master` or run **Deploy storefront to GitHub Pages** from the Actions tab.

The Pages URL appears in the successful workflow run under the `github-pages` deployment environment.
