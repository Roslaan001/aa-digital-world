CLOUDFLARE PAGES

Manage your shop.

The storefront and admin run on Cloudflare Pages. Pages Functions handle sign-in and catalog updates, while R2 stores the product photos and catalog data.

1. Connect the repository

In Cloudflare, open Workers & Pages → Create application → Pages → Connect to Git and select the AA Digital World repository. Use master as the production branch and public as the build output directory. Leave the build command empty.

2. Add the R2 bucket

Create an R2 bucket named aa-digital-world-product-images. The repository's wrangler.toml config binds it to the Pages Functions as PRODUCT_IMAGES. If you manage bindings in the dashboard instead, use that same variable name and bucket.

3. Add private login secrets

Under Settings → Variables and Secrets, add encrypted secrets named ADMIN_EMAIL, ADMIN_PASSWORD, and SESSION_SECRET. The session secret should be a long random value. Redeploy after adding the binding and secrets.

4. Manage products

Open the catalog admin ↗, sign in, and add or edit products. Saving updates the live catalog. Product images are stored in R2.

Keep the password private

The username, password, and session secret belong in Cloudflare's encrypted project secrets. Never add them to the source files.
