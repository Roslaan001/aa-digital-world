PUBLISHING GUIDE

Publish catalog updates.

The shop is a static GitHub Pages site. The editor creates a catalog file; committing that file publishes the changes.

1. Edit products

Open the catalog editor ↗, add or edit items, choose photos and set availability. Photos are included in the exported JSON file. Keep each photo at or below 2 MB.

2. Download the catalog

Select Download catalog.json. The editor works on a draft in this browser tab; download before you reload or close it.

3. Replace the site catalog

On a computer with the website repository cloned, copy the downloaded file over public/catalog.json. From the repository folder run:

git add public/catalog.json
git commit -m "Update product catalog"
git push origin HEAD:master

The GitHub Actions workflow publishes the new catalog and storefront. The products become visible after Pages finishes deploying.

Static hosting limits

This editor has no sign-in and cannot write to GitHub by itself. The username and password you suggested are not included in the public site. Only a GitHub commit updates the live catalog.
